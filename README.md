# Roach Rancher

Roach Rancher is a small experimental 3D game project built with **Godot 4**.

The game is planned as a lighthearted ranching and action game, centered around managing a small ranch, interacting with creatures, and dealing with hostile encounters.

## Planned Features

- Small 3D ranch and surrounding areas
- Creature management
- Simple combat and enemy AI
- Resource gathering and progression
- Ranch upgrades and customization
- Increasingly chaotic encounters

The game will start deliberately small, with individual mechanics being prototyped and tested before expanding the scope.

## Development Status

**Early development / incomplete**

The project is currently at the initial setup stage. Most gameplay systems and features described above have not been implemented yet.

Development will be incremental, with the focus on experimenting with the core gameplay before committing to larger systems.
